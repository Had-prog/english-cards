# Сайт для изучения английского языка

Простой веб-проект для тренировки английского языка. Сайт включает интерактивные карточки со словами, адаптивную верстку и минималистичный дизайн. Проект создан для отработки навыков фронтенд-разработки и демонстрации понимания связки HTML + CSS + JS.

## Функционал

- Интерактивные карточки: переключение между словом и переводом по клику.
- Адаптивная верстка: корректное отображение на мобильных устройствах и десктопах.
- Фоновое изображение с затемнением для лучшей читаемости текста.
- Динамическое обновление контента через JavaScript без перезагрузки страницы.

## Стек технологий

- **HTML5** — семантическая разметка и структура страницы.
- **CSS3** — стилизация, Flexbox/Grid-верстка, адаптивность.
- **JavaScript (ES6+)** — логика взаимодействия, обработка событий.

## Как запустить проект

### Вариант 1: Локальный запуск (самый простой)

1. Скачайте репозиторий или клонируйте его.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge).

### Вариант 2: Через локальный сервер (рекомендуется)

Для корректной работы некоторых JS-функций или при расширении проекта лучше использовать локальный сервер:

1. Убедитесь, что у вас установлен Node.js.
2. В терминале в папке проекта выполните:
   ```bash
   npx http-server
